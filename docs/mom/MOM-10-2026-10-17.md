## 1. Discussion Points

### 1.1 Homework Management

Team agreed to consolidate homework-related use cases into one diagram instead of maintaining separate diagrams for each homework function.

Consolidated homework diagram: `docs/diagrams/use-case/Usecase_Diagram.drawio.xml`, with preview `docs/diagrams/exports/Usecase-Diagram.svg`.

- Actors: Lecturer and Student.
- Lecturer: Manage Homework; Create Homework; Assign Homework to Class/Group; Select Class/Group; Set Homework Deadline; Grade Homework; Review Submission.
- Student: View Assigned Homework; Download Homework Materials; Submit Homework; Update Submission.
- Shared: Set Reminder; Receive Reminder; View Submissions and Result.
- Supporting behavior: Upload Homework Material; Attach Submission Content (File Upload / External Link); Provide Feedback.
- Assignment includes Create Homework, Select Class/Group, and Set Homework Deadline; Upload Homework Material extends assignment.
- Grade Homework includes Review Submission; Provide Feedback extends grading.
- Download Homework Materials extends View Assigned Homework.
- Submit Homework and Update Submission both include Attach Submission Content.

Student homework submission belongs to this consolidated homework area; a separate submission diagram is no longer needed.

### 1.2 Class and Group Management

Reviewed [Class and Group Management diagram](../diagrams/use-case/uc-manage-class-and-group.drawio):

| Actor | Diagram capabilities |
| :--- | :--- |
| Lecturer | Manage Classes; Add Student to Class; Manage Groups; Add Member to Group. |
| Student | Manage Groups; Add Member to Group; Join Class via Invite Link; Join Group. |

Class/group membership management remains separate from assigning homework to a class/group. Homework assignment belongs to consolidated Homework Management diagram.

### 1.3 Homework Calendar

Retained [Homework Calendar diagram](../diagrams/use-case/uc-view-homework-calendar.drawio) without changes. Existing scope:

- Actors: Lecturer and Student.
- Both actors can View Homework Calendar.
- Both actors can Filter Calendar Events.
- Both actors can View Homework Details.

Calendar remains separate diagram focused on discovering homework and deadlines, rather than duplicating homework editing, submission, or grading flows.

| Decision | Details |
