# Homework Management System

Homework-management system for lecturers and students.

## MVP Scope

- Manage homework.
- Set deadlines and reminders.
- Manage classes/groups and assign homework.
- Submit, grade, and provide feedback on homework.
- View homework and deadlines on a calendar.
